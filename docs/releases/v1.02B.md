# EventClock v1.02B — Circular Time Selection Wheels

**Status:** published on GitHub as EventClock v1.02B. Physical iPhone validation completed. This is not an App Store release.

## Highlights

- Shared native-looking duration wheels for timer presets, automation-rule timer actions, and relative-event countdowns.
- Minutes and seconds scroll continuously in both directions:
  - 00 backward reaches 59.
  - 59 forward reaches 00.
- Hours remain finite at 0–24; existing duration validation is unchanged.
- The seconds-wheel regression found in the first physical test is fixed.
- Native wheel appearance, haptics, and VoiceOver behavior are preserved.
- Absolute recovery date/time editors remain native date pickers and are unaffected.

## Bug fix

The first physical validation found that seconds did not wrap while minutes did. The seconds component could remain at virtual row 0 when its value was 00, so there was no preceding row to scroll backward into. Synchronization now repositions any circular component found at a virtual edge even when its modulo value matches, and performs one synchronization after the picker’s first real layout.

## Validation

- **71 automated tests passing**, 0 failures:
  - 54 Core tests
  - 17 notification-platform tests
- iOS simulator-SDK and device-SDK builds succeeded.
- Physical iPhone acceptance confirmed:
  - Minutes and seconds wrap in both directions.
  - Saved `01:59:59` restores correctly.
  - Boundaries `00:00:00`, `24:00:00`, and `24:00:01` behave as expected.
  - Circular wheels work in preset, automation-rule, and relative-event editors.
  - Existing timer, preset, automation, and recovery data remains intact.

## Known limitations

- Hours are finite and do not wrap.
- iOS controls notification delivery; notifications are not guaranteed.
- No continuous background rule engine.
- No HealthKit, AlarmKit, watchOS, or real sensor integrations yet.
- Reset times are user-supplied estimates; EventClock does not access service accounts or private usage APIs.
- No license has been selected.
- No App Store distribution has been prepared.

## Installation

Requirements: Xcode 27 / Swift 6, iOS 17+, and an Apple signing team.

1. Open `App/EventClock.xcodeproj`.
2. Select the EventClock target → Signing & Capabilities → choose your team.
3. Build and run on an iPhone.
4. Allow notifications.

The app displays `EventClock v1.02B` and technical build `6`. Apple-facing numeric metadata is `1.1.0`.
